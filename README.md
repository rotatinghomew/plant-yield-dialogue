# 联产加工月结资料交换

`data/` 收录供演练使用的合成记录，不含真实企业或人员资料。资料使用 UTF-8 逗号分隔，首行为字段名，带逗号的单值用双引号括起。日期采用 ISO 表示，空字段表示来源未填或不适用，不代表数值零。`sources.json` 记录各表列名、身份键和可直接核对的引用。

## 业务资料

- `transfers.csv`：交接有向边，批号、来源厂、去处及阶段。量以 unit 区分；equiv 是有凭证的标准件数，未填不可折。
- `acceptances.csv`：验收去向、通过与返修量，occurred 属于业务期间，seen 是确认时间。revision 是对同一 receipt 的完整替代。
- `checks.csv`：合并之前的可追溯检验事实，已发生的首检失败不能因下游复验通过而消失；证据只覆盖列出的量。
- `attribution.csv`：带来返修的来源份额；同 receipt 和 revision 的多条份额组成一次责任确认。无份额的部分不强配。
- `close.csv`：月结时点、发布粒度和该期重发门槛。late_min_delta 为首过标准件的最低绝对变化。
- `sites.csv`：工厂行政归属。
- `review.csv`：复盘的现有业务回执。

生产归属视角按接收并最终交付的厂，责任视角按当期能看到的返修责任；责任份额是对有关返修标准件量的比例。不同视角不能把同一次验收计两遍。月报发布上允许客户和区域两维，不泄露单件。复盘完成量是该负责人已处理的量。上游检验可用于识别重复验收；不能用首过和各段失败数相加重复扣同一量。

## 月结对账口径（`monthend/`）

`monthend` 包在交换资料之上实现同一份业务口径的对账引擎，纯标准库、无第三方依赖：

- `loader.py`：结构与业务自洽校验。空字段保持空缺，不解释为零；份额合计、验收量自洽、换算凭据完整性在这里拦截。
- `trace.py`：领料路由与拆并批交接的路径还原。拆分按每条边的量归去处；合并不抹任一原批的检验事实（`checks` 沿整条交接路径回溯）；缺换算凭据的边标为不可比，暴露量但不进标准件分母。
- `responsibility.py`：同一回执返修量分四类——正式确认（signed）、共担比例（provisional）、尚未认领（unclaimed）、无法分摊（unallocatable），四类相加等于返修量。责任份额对应返修量而非交付量，因此责任方层级没有共同交付分母，只给量与缺口，不虚算首过率。
- `pivots.py`：区域、客户、厂、工段四个生产视角从各单元适用的分子分母重算首过率，不平均各厂比例；责任视角只汇总量。`reconcile` 核对同一回执集合在各视角的分母一致。
- `periods.py`：处理中口径（无视关账时点取最新修订版）与已签发口径（`seen <= cutoff`）分开；迟到更正按 `late_min_delta` 与 `reissue_until` 判定是否符合该期重发，并给出旧口径结果；关账后的责任签字只进复盘，不改对外已签产量。
- `review.py`：复盘单四种处置——保留结案（KEEP_CLOSED）、数量扩大或改派则再开（REOPEN，原记录保留）、未结案差异被新凭证覆盖则确认不再待办且不重复发单（RESOLVED_BY_EVIDENCE）、仍有待办（STILL_OPEN）。
- `reports.py` / `cli.py`：组装对内复盘包与对外月报；差异说明可回到透视单元、交接贡献路径与未分配量。

### 生成月结输出

```
python3 -m monthend.cli --period 2026-03 --explain
```

在 `out/` 写出该期四件产物：`*_working.json/_working.md`（对内复盘包，含全部视角、责任四类、复盘处置、可追溯检验）、`*_issued.json/_issued.md`（对外月报，仅关账约定允许的 region/customer 单元）、`*_differences.json`（可回溯差异说明）。不带 `--period` 时处理 `close.csv` 中的全部关账周期；新增周期只需追加同格式资料，引擎不改。

## 本地核对

资料核对使用 Python 3.11 标准库，无需额外安装。

从仓库根目录执行 `python3 check_sources.py`，返回各表行数；其他同格式资料可用 `python3 check_sources.py 路径` 检查。脚本只读资料并报告结构或引用错误，不给出业务结论。执行 `python3 -m unittest discover -s tests -v` 检查资料约定、拒绝重复身份的行为，以及路由回溯、责任四类口径、透视重算、关账双视角、迟到更正与复盘生命周期的完整口径（合成资料在临时目录构造，不写入 `data/`）。
